## About Me

I am a Senior DevOps Engineer and Cloud Infrastructure Architect with 4+ years of experience designing, automating, and operating production-grade infrastructure across cloud, hybrid, and enterprise environments.

My work focuses on building reliable Kubernetes platforms, implementing Infrastructure as Code, engineering CI/CD ecosystems, and improving infrastructure security, scalability, and operational efficiency.

I also have a strong backend engineering background, primarily working with Python, Django REST Framework, and PostgreSQL.

### What I Do

- Design and architect scalable cloud and hybrid infrastructure.
- Build and operate production Kubernetes platforms.
- Automate infrastructure provisioning and configuration using Terraform.
- Engineer CI/CD pipelines and GitOps deployment workflows.
- Implement monitoring, observability, and reliability engineering practices.
- Improve cloud security, identity management, and infrastructure hardening.
- Develop backend services and automation tools using Python.
