## 👨‍💻 About Me

I am a Senior DevOps Engineer and Cloud Infrastructure Architect with 4+ years of experience designing, automating, securing, and operating production-grade infrastructure across cloud and hybrid environments.

My expertise spans Kubernetes orchestration, Infrastructure as Code, cloud architecture, CI/CD engineering, DevSecOps, GitOps, and observability.

I work across AWS, Azure, GCP, and hybrid enterprise environments, focusing on building resilient platforms, automating operational workflows, and improving system reliability.

Beyond infrastructure engineering, I enjoy software development in my free time, particularly building backend systems with Python and cross-platform applications with Flutter.

### What I Do

- Architect scalable cloud and hybrid infrastructure.
- Build and manage production Kubernetes platforms.
- Automate infrastructure provisioning using Terraform and GitOps.
- Engineer CI/CD pipelines and deployment automation.
- Implement DevSecOps practices and cloud security controls.
- Design monitoring, observability, and reliability ecosystems.
- Develop backend services and automation tools using Python.
- Build cross-platform applications using Flutter and Dart.
